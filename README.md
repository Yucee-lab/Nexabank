NexaBank – Digital Banking Dashboard

A modern, responsive digital banking website built with HTML, CSS, and JavaScript. NexaBank provides a clean and user-friendly banking dashboard designed to make managing finances simple and convenient.

Features

- Account Overview: Displays total account balance.
- Income Tracking: Shows total income and monthly growth.
- Expense Tracking: Displays spending information.
- Quick Actions: Transfer, add money, buy airtime, and pay bills.
- Transaction History: Displays recent incoming and outgoing transactions.
- Account Information: Displays account number and profile details.
- Copy Account Number: Allows users to copy their account number.
- Responsive Design: Optimized for desktop, tablet, and mobile devices.

Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling, layout, and responsive design.
- JavaScript – Interactive elements and functionality.

Getting Started

Follow these steps to run the project locally.

1. Clone this repository:

git clone https://github.com/Yucee-lab/nexabank.git

2. Open the project folder in Visual Studio Code.

3. Open "index.html" using your browser or VS Code Live Server.
